# 🏦 Retail Bank Analytics Dashboard | Power BI

## 📌 Project Overview

The Retail Bank Analytics Dashboard is an interactive business intelligence project developed using Microsoft Power BI. It analyzes retail banking data to generate insights into customer behavior, account activity, transactions, loan performance, and card usage.

## 🎯 Project Objectives

- Analyze customer demographics and engagement.
- Monitor account balances and account status.
- Identify transaction trends and high-performing channels.
- Analyze loan distribution, repayments, interest, and penalties.
- Evaluate card activation, credit limits, and outstanding balances.
- Support data-driven banking decisions through interactive dashboards.

## 🛠️ Technologies Used

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Cleaning and Transformation
- Data Visualization and KPI Development

## 📊 Dashboard Pages

1. **Executive Banking Summary** – Overall banking performance and key KPIs.
2. **Customer Analytics** – Customer demographics, segments, income, and signup trends.
3. **Accounts Analytics** – Account types, account balances, and account status.
4. **Transactions Analytics** – Transaction trends, channels, and customer segments.
5. **Loans Analytics** – Loan types, repayments, interest, and penalties.
6. **Cards Analytics** – Card types, activation, credit limits, and outstanding balances.

## 🔍 Key Business Insights

- Analyzed 500 customers and 700 accounts.
- Evaluated approximately 5,000 transactions worth 35.89 million.
- Identified online banking as the highest transaction-value channel.
- Analyzed 300 loans to understand repayment behavior and loan performance.
- Evaluated 600 cards and identified opportunities to improve card activation.

## 💡 Business Value

The dashboard helps banking stakeholders monitor performance, understand customer activity, compare transaction channels, evaluate loan repayment behavior, and identify opportunities to improve customer engagement and card usage.

## 🚀 How to View the Project

1. Download the `.pbix` file from this repository.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file in Power BI Desktop.
4. Explore the dashboard pages and available interactive filters.
